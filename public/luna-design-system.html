Design System Reference

XP:LUNA

A portfolio site rebuilt as a Windows XP desktop — glossy Luna-blue chrome, a BIOS boot sequence, and windows you actually drag. This page catalogs the color, type, and icon system that makes the illusion hold together.

Skins: Blue · Silver · Olive UI face: Tahoma Document face: Courier New Console face: Consolas Hand-built icons: 2

01 — Color

Three skins, one set of tokens

Every gradient in the chrome is a CSS custom property. Switching skins doesn't swap components — it swaps the values those components already point at. Blue (Luna) is the default and the only skin with a photographic wallpaper; Silver and Olive replace it with a flat tonal gradient instead.

02 — Typography

Three faces, doing three jobs

The UI runs on Tahoma, the way the real OS did. Anything meant to look like a printed or terminal document — Notepad, a crash screen, the BIOS itself — drops into Courier New. The Terminal app gets its own, slightly more modern console face, because a command line should feel like a command line, not a typewriter.

03 — Icons

Two hand-built, everything else borrowed

Out of every icon on the desktop, exactly two are custom artwork — the rest is plain emoji, rendered as literal text by a component that only asks one question: does the icon string start with a slash? If yes, it's an image. If no, it's a character. Two icons earned the "yes."

04 — Window Chrome

The anatomy of a glossy button

Every gradient in the chrome follows the same recipe: a bright highlight stop near the top, a long flat mid-tone, a darker stop at the bottom. Hover states never swap the gradient — they just brighten it. It's the one interaction rule the entire desktop shares.
